# Morarji Desai Residential School Memory App (MDRS)

A premium, nostalgic memory portal and alumni hub for Morarji Desai Residential School, Dorigudda.

## Features
- Luxury Rose Gold & Burgundy Visual Theme
- 3D Pink MDRS Official Brand Icon
- Interactive Class 10th Farewell Uniforms
- Teachers Voice Soundboard
- Comprehensive Alumni Directory & Batches
- 24-Hour Campus Routine Timeline
- Nostalgic MDRSian Bingo

## Tech Stack
- Flutter 3.11+
- Dart 3.11+
- Material 3 Design System
- Shorebird CodePush
- Supabase Backend Integration
